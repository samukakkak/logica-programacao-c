# Lógica de Programação e C

Este repositório foi criado para ajudar você a aprender lógica de programação e a linguagem C de forma prática e em ordem crescente de dificuldade.

## Objetivo

- entender a lógica por trás dos algoritmos;
- praticar resolução de problemas passo a passo;
- aprender a escrever programas em C;
- evoluir de exercícios simples para projetos pequenos.

## Estrutura do repositório

- `01-logica/` — exercícios focados em lógica, sem depender de uma linguagem específica.
- `02-c/` — exercícios em C, com foco em sintaxe e estruturas fundamentais.
- `03-projetos/` — desafios maiores para praticar tudo junto.

## Como estudar

1. Comece pela pasta `01-logica`.
2. Resolva os exercícios em pseudocódigo ou em papel antes de programar.
3. Passe para a pasta `02-c` e implemente os mesmos exercícios em C.
4. Finalize com os mini projetos em `03-projetos`.

## Sequência sugerida

- Variáveis e entrada/saída
- Operadores e expressões
- Condicionais
- Laços de repetição
- Funções
- Vetores
- Estruturas básicas de dados
- Projeto final simples

## Dicas importantes

- escreva em linguagem simples;
- teste seus programas com valores diferentes;
- leia o enunciado com atenção antes de programar;
- comece pelos exercícios fáceis e avance gradualmente.

## Recomendação de estudo

É melhor resolver 5 exercícios pequenos por dia do que tentar um desafio muito grande de uma vez. A prática constante é o que faz a diferença.
