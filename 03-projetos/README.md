# 03 - Mini Projetos

Agora que você já praticou lógica e C, é hora de juntar tudo em pequenos projetos.

## Projeto 1: Calculadora
Crie uma calculadora que:
- leia dois números;
- leia a operação;
- execute a operação escolhida;
- mostre o resultado.

## Projeto 2: Jogo de adivinhação
Crie um jogo onde:
- o computador escolhe um número secreto;
- o usuário tenta adivinhar;
- o programa informa se o número é maior ou menor;
- termina quando acertar.

## Projeto 3: Agenda de contatos
Crie um programa que permita:
- cadastrar contato;
- listar contatos;
- buscar por nome;
- apagar ou atualizar contato.

## Projeto 4: Sistema simples de notas
Crie um sistema que:
- cadastre alunos;
- leia as notas de cada aluno;
- calcule a média;
- mostre se o aluno foi aprovado ou reprovado.

## Projeto 5: Lista de tarefas
Crie uma lista com:
- adicionar tarefa;
- remover tarefa;
- marcar como concluída;
- listar todas as tarefas.

## Recomendação

Comece pelo Projeto 1 e avance conforme for ficando mais confortável com a linguagem.

A prática real é o melhor caminho para aprender programação em C.
